# Jb Yashvi — portfolio

Personal portfolio site: selected work, case studies, gallery and résumé.

Built with React, TypeScript and Vite.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Deployed on Vercel; every push to `main` redeploys. `vercel.json` sends page routes such as
`/gallery` and `/work/<project>` to the app so they load when opened directly.
